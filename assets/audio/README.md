# Background music

Put your music file here, named exactly:

```
assets/audio/music.mp3
```

The mute/unmute button on the site will work as soon as this file exists —
no code changes needed.

## Where to get a royalty-free track (safe to use / no copyright issues)

- **YouTube Audio Library** (studio.youtube.com → Audio Library) — free, downloadable, filter by "no attribution required".
- **Pixabay Music** (pixabay.com/music) — free for commercial and personal use, no attribution required.
- **Free Music Archive** (freemusicarchive.org) — filter by license; pick CC0 or check attribution requirements.

Search for something like "romantic instrumental", "shehnai", or "indian
wedding background music" on those sites. Avoid using a copyrighted
Bollywood song clip directly on a public website, even if it "sounds nicer" —
that can get the track muted/blocked once shared widely, and can carry
copyright risk if this ever goes on a paid/public domain.

Once you have the file, just drop it in this folder as `music.mp3` and
refresh the page.
